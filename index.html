Come funziona
I dati vengono salvati su un Gist privato GitHub e caricati automaticamente ad ogni apertura.

1. Vai su GitHub → Settings → Developer settings → Personal access tokens
2. Crea un token con scope gist
3. Incollalo qui sotto e clicca Connetti
👋 Primo accesso da questo browser.
Inserisci token e Gist ID per caricare i dati già salvati.
